

## Future: AI-Powered Background Removal (rembg/SAM)

For a later phase, replace the image-gen-based background removal with a dedicated AI model:

### Approach
- Use **rembg** (Python library wrapping U2-Net) or **Segment Anything Model (SAM)** for precise subject isolation
- Deploy as a lightweight Python microservice alongside the Node backend, or use a WASM build of rembg for browser-side processing
- Endpoint: `POST /api/images/remove-background` accepts image URL, returns processed image with transparent/white background

### Benefits over Image Gen Approach
- Pixel-perfect: preserves original image quality, only removes background
- No credits consumed (no LLM/image gen API call)
- Instant (seconds vs 30-60s generation time)
- No risk of the AI "reinterpreting" the subject

### Implementation Sketch
- Python service: FastAPI + rembg, Docker container
- Accepts image URL or base64, returns PNG with alpha channel
- Frontend converts alpha to white background if needed
- Integrate into the enhanced modal as a replacement for the "Remove Background" button's backend call

### When to Build
- After Phase 1 ships and users validate the image-gen approach works
- If users report quality issues with gen-based background removal, prioritize this
