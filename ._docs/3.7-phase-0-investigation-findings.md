## Investigation A: Scene Instance Regen Quality

### Traced Code Path (Stage 8 Image Generation)

```
Frontend: VisualStateEditorPanel.tsx → onGenerateImage(instanceId)
  → Stage8VisualDefinition.tsx → sceneAssetService.generateSceneAssetImage(projectId, sceneId, instanceId)
    → POST /api/projects/:id/scenes/:sid/assets/:iid/generate-image (empty body)
      → sceneAssets.ts endpoint → fetches Stage 5 visual style
        → ImageGenerationService.createSceneAssetImageJob(instanceId, projectId, branchId, visualStyleId, manualVisualTone)
          → Fetches scene_asset_instances.* + project_assets(asset_type, image_key_url)
          → Builds prompt from effective_description
          → createImageJob() with referenceImageUrl + visualStyleCapsuleId
            → executeJobInBackground() → prepends identity ref before style refs → provider.generateImage()
```

### Results

| Check | Status | Location | Notes |
|-------|--------|----------|-------|
| effective_description used (not just master) | PASS | `ImageGenerationService.ts:219` | Uses `instance.effective_description` which resolves override > master |
| status_tags included in generation prompt | **FAIL** | `ImageGenerationService.ts:219` | `instance.status_tags` was fetched from DB (via `SELECT *`) but never injected into prompt |
| master reference image attached | PASS | `ImageGenerationService.ts:234` | `instance.selected_master_reference_url \|\| projectAsset.image_key_url` |
| visual style capsule applied | PASS | `ImageGenerationService.ts:291-352` | Both textContext (descriptors + pillars) and reference images from capsule |
| identity ref prepended before style refs | PASS | `ImageGenerationService.ts:333` | `unshift` places master ref first |
| post_description used for transformations | PASS | `sceneAssets.ts:1838` | `event.post_description` used as prompt |
| post_status_tags in transformation prompt | **FAIL** | `sceneAssets.ts:1834-1848` | `event.post_status_tags` exists in DB but was not appended to prompt |
| pre-transformation image as reference | PASS | `sceneAssets.ts:1832` | `assetInstance.image_key_url \|\| projectAsset.image_key_url` |

### Fixes Applied

**Fix 1** — `backend/src/services/image-generation/ImageGenerationService.ts` (line ~218):
- Added status_tags injection into `createSceneAssetImageJob()` prompt
- If `instance.status_tags` has entries, appends `. Visual modifiers: tag1, tag2.` to effective_description before background isolation injection

**Fix 2** — `backend/src/routes/sceneAssets.ts` (line ~1834):
- Added post_status_tags injection into transformation post-image generation
- If `event.post_status_tags` has entries, appends `. Visual modifiers: tag1, tag2.` to post_description

